# m-talks2

## Stack

- TanStack Start, TanStack Router (file-based), and TanStack Query (SSR-integrated)
- React 19, Tailwind CSS v4, and shadcn/ui-style primitives (Radix + CVA)
- Cloudflare Workers via `@cloudflare/vite-plugin`
- Biome for formatting and linting, Vitest for tests

## Local setu

```bash
bun install
cp .env.example .dev.vars
bun run cf-typegen   # generates worker-configuration.d.ts from wrangler.jsonc
bun run db:migrate:local && bun run db:seed:local   # local D1 + sample data
bun run dev
```

## AI and tracing

- **Nicrron** (`src/server/nicrron.ts`): the model gateway, OpenAI-compatible, so it
  uses the stock `openai` SDK pointed at `NICRRON_BASE_URL`. `NICRRON_MODEL` defaults
  to `nicrron/auto` (smart routing).
- **PRISM** (`src/server/prism.ts`): every model turn in `src/server/chat.ts` POSTs one
  trace (success or error) with a `sessionId`, which groups turns into a trajectory.
  Tracing is a no-op when `PRISMTRACE_API_KEY` is unset.
- **`POST /api/chat`**: `{ messages, model?, models?, temperature?, sessionId? }` →
  `{ message, model, sessionId }`. Reuse the returned `sessionId` for follow-up turns.

```bash
curl -s localhost:3000/api/chat -H 'content-type: application/json' \
  -d '{"messages":[{"role":"user","content":"hello"}]}'
```

- **AI import** (`/import`, `POST /api/imports` with a multipart `file`): a PNG, JPEG,
  WebP or PDF of a vendor invoice (10 MB max, type checked by magic bytes) is stored
  in R2 (`UPLOADS`), transcribed through Nicrron with a `models` fallback list, and
  returned as an editable draft with uncertain fields flagged. Images go to
  `IMPORT_MODEL` then `IMPORT_FALLBACK_MODELS`; PDFs go as an OpenAI `file` part to
  `IMPORT_PDF_MODELS` only, because Anthropic models behind Nicrron silently ignore
  `file`/`document` parts. Sample scans: `data/scans/` (made by
  `scripts/render-scans.ts`).

```bash
curl -s localhost:3000/api/imports -F file=@data/scans/inv-1004.png
```

## Layout

```
src/
  config/        site identity (site.ts) and navigation (nav.ts)
  components/
    ui/          design-system primitives; use semantic tokens only
    app-shell.tsx  sidebar/mobile shell, PageHeader, PageBody
  hooks/         client hooks (use-theme)
  integrations/  TanStack Query context + devtools panel
  lib/           utils (cn), theme bootstrap
  routes/        file-based routes; routeTree.gen.ts is generated by `dev`/`build`
  server/        server-only code: env, Nicrron client, PRISM tracing, chat
  styles.css     semantic design tokens (the only place colors live)
```

## Theming

All colors are semantic CSS variables in `src/styles.css`, exposed as Tailwind
utilities through `@theme inline`: `background`, `foreground`, `card`,
`popover`, `primary`, `secondary`, `muted`, `accent`, `destructive`, `success`,
`warning`, `info`, `border`, `input`, `ring`, `chart-1..5`, and `sidebar-*`.

Use `bg-primary text-primary-foreground`, `text-muted-foreground`, and so on
in components. Do not use raw palette classes (`bg-zinc-900`, `text-white`).
To re-brand the app, edit the `:root` and `.dark` values.

Dark mode is class-based (`.dark` on `<html>`). It follows the system setting
by default, and the user's choice is stored in `localStorage`.

## Scripts

| Script | Purpose |
| --- | --- |
| `dev` / `build` / `preview` | Vite dev server, production build, preview |
| `deploy` | Build and `wrangler deploy` |
| `cf-typegen` | Regenerate Worker binding types |
| `typecheck` / `test` | `tsc --noEmit` / `vitest run` |
| `check` / `lint` / `format` | Biome |
| `db:generate` | Generate a migration from `src/db/schema/` (after rebasing on `main`) |
| `db:migrate:local` / `db:migrate:remote` | Apply migrations to local / deployed D1 |
| `db:seed:local` / `db:seed:remote` | Upsert `data/` into D1 (never touches runs or approvals) |

Add shadcn components with `bunx shadcn@latest add <name>`; `components.json`
is already configured for the `#/` alias.
